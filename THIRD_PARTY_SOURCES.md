# Third-Party Sources

The public `MAnasLatif/CTO` repository contains the original CTO wrapper,
catalog, synchronization tooling, and project documentation. It does not include
the specialist payloads listed in `skills/cto/references/subskills.json`.

The full-pack installer downloads those payloads directly from their recorded
upstream repositories into `skills/cto/subskills/`, which Git ignores. Each
payload remains governed by its upstream license and notices. The project's MIT
License does not grant rights to any synchronized third-party content, names, or
trademarks.

Synchronization records source revisions, recovery provenance, hashes, legal
files, and static command indicators in local generated reports. These reports
support review but do not replace upstream license terms or a security audit.
Review a specialist and its upstream terms before execution or redistribution.

No third-party script is executed by the synchronization process. Some
specialists contain executable examples or utilities; the CTO wrapper requires
explicit review and user approval before any such script is run.
